# Changelog of the blockcharts principles

## 1.1 — 2026-10-26

A seventh role, `lib` (§2): code that other blocks share, which a spec never names. A block lists it in `requires`
and reaches it through the core, so §12.7 holds. The first is `lib.curve`, the path of `mark.line` and `mark.area`.
The table of §2 also lists `scale.size` and `transform.window`.

## 1.0 — 2026-09-28

The first written version: exactly what the charts need, nothing more (§1), blocks as atoms (§2),
customizable at every level (§3), the page as the product (§4), specs as data (§5), declared once (§6),
checked before written (§7), heavy data (§8), determinism (§9), nothing leaves the page (§10), three ways
in (§11), and the requirements (§12).
